# GREEN BEER PIZEDES — Sega Mega Drive / Genesis 16-bit (Test ROM)

Играбельный вертикальный срез (**Vertical Slice**) для оригинальной **Sega Mega Drive / Genesis (M68k + VDP + YM2612 + SN76489)** на базе **SGDK 2.x**.

## Что входит в тестовый ROM
- **Титульный экран** с 16-цветной пиксельной заставкой, выбором режима (`1P VADEK`, `1P ZAVOD KILLER`, `2P CO-OP`) и темой на чипе **YM2612 FM + PSG**.
- **Уровень 1 — Бар «Заводной»**: двухслойный аппаратный параллакс (`BG_B` ночной силуэт завода + `BG_A` улица с баром), нескроллящийся верхний **HUD на слое `WINDOW`**.
- **2 героя и локальный 2P Co-Op** на двух геймпадах (`JOY_1` и `JOY_2`):
  - **VADEK**: удар колесом (`28` урона) + дробовик (3 дробины).
  - **ZAVOD KILLER**: тяжёлый удар стальной трубой (`46` урона + отбрасывание) + огнемёт «Домна».
  - Буферы ввода (12 кадров) на прыжок и ближний удар + удержание кнопок.
- **3 боевые волны + Босс**:
  - Уличные панки (`drunk`),
  - Отдельная волна летающих **квадрокоптеров (`quad_drone`)** — достаются только в прыжке,
  - **Босс «Пивной Бармен»** (`48×64`, полоска HP на HUD, броски бутылок, отдельная босс-тема на YM2612).
- **Хилки** (пиво, шаурма, картошка фри, рулька) и **7 оцифрованных PCM SFX (14 кГц)** через Z80-драйвер XGM.

## Управление (3-кнопочный / 6-кнопочный геймпад)
- **D-Pad**: движение в 8 направлениях
- **A**: ближний удар (колесо / труба)
- **B**: стрельба (удержание)
- **C**: прыжок
- **START**: пауза / старт

## Как собрать `.bin` ROM

### Вариант 1 — Автосборка в GitHub Actions
Запушьте репозиторий в GitHub или запустите workflow **«Build Sega Mega Drive ROM»** вручную во вкладке **Actions** → скачайте артефакт **`green-beer-pizedes-md.bin`**.

### Вариант 2 — Локально за 1 команду (через Docker)
```bash
node scripts/export-md-assets.mjs
node scripts/export-md-vgm.mjs
docker run --rm -v "$PWD/megadrive:/src" ghcr.io/stephane-d/sgdk:latest make -f /sgdk/makefile.gen
```
Готовый ROM появится в `megadrive/out/rom.bin`.

## Запуск
Открывайте `green-beer-pizedes-md.bin` (или `megadrive/out/rom.bin`) в **BlastEm**, **RetroArch (Genesis Plus GX / PicoDrive)**, **Gens** или на реальной Sega Mega Drive через флеш-картридж (EverDrive / MegaSD).
